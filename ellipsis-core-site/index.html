BUILT TO WAIT WELL

Anything slow gets a skeleton.

Images, sections and whole pages show a placeholder while they load. Redis keeps sessions and cache outside the app, so you can run more than one copy.

Businesses

Redis is off by default so the scaffold runs anywhere. Set REDIS_ENABLED=true and REDIS_URL in .env before you run more than one instance.

What it does

1Clones the scaffold into ~/.ellipsis, or pulls it if it's already there.
2Links the ellipsis-core skill into your harness's skills folder.
3Adds ELLIPSIS_REPO to your shell profile so the skill can pull the latest scaffold.
4Start a new session, then ask for your first app.

Then start an app

build me an ellipsis app called my-app

Or run /ellipsis-core. To update later, run git -C ~/.ellipsis pull.
